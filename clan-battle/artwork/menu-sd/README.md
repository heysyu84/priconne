# 메뉴별 SD 일러스트

내장 `image_gen.imagegen`으로 공식 캐릭터 일러스트와 사용자가 첨부한 아그라이아 자료를 참고해 제작했습니다. 실제 사용 프롬프트와 수정 이력은 [prompts.json](./prompts.json)에 있습니다.

## 적용한 8명

| 메뉴 | 캐릭터 | 장면 |
| --- | --- | --- |
| 상황판 | 페코린느 | 주먹밥을 들고 반기는 모습 |
| 대시보드 | 콧코로(嚮導幼君) | 초록 영혼새와 잎으로 안내 |
| 배틀로그 | 캬루(편입생) | 깃펜으로 기록 |
| 택틱 작업실 | 쿄우카(고딕) | 책과 고양이 인형 뒤에서 빼꼼 |
| 추천 조합 | 리리(서머) | 팔을 베고 다섯 꽃 장식을 살펴봄 |
| 월간 순위 | 호우오우 | 봉황과 트로피, 손은 두 개 |
| 개인 이력 | 밤피(서머) | 앨범을 끌어안고 엎드림 |
| 클랜 DB | 아그라이아 | 팔베개, 무릎을 굽혀 맨발을 든 포즈 |

티아를 스페어로 옮기고 리리(서머)를 적용했습니다. 아그라이아의 맨발, 후광과 의상은 사용자 참조를 우선했습니다.

## 저장 경로

사이트 경로는 `public/images/menu-sd/`이며 Pages 배포본은 `docs/images/menu-sd/`입니다.

| 폴더 | 용도 |
| --- | --- |
| `headers/` | 현재 메뉴용 8장, 576×384 WebP, 알파 투명도 유지 |
| `archive/headers/` | 메뉴 그림 8장의 전체 해상도 보관본 |
| `archive/full-body/` | 1군 8명의 전신 보관본 |
| `reserve/` | 티아·바이올렛(이자나미)·루이즈마리(서머) 전신 3장 |
| `archive/studies/` | 재사용할 수 있는 이전 포즈 및 정사각형 연구본 |
| `catalog.json` | 메뉴 연결, 캐릭터 이름, 보관 경로와 공식 참조 ID |

전신은 총 11명 보관했습니다. 3개의 손이 생긴 오류 그림은 배포하지 않습니다. 원본 생성 PNG는 별도로 남겨 두고 사이트용 파일만 WebP로 인코딩했습니다. 화면용 이미지는 종횡비를 유지해 축소했습니다.

현재 메뉴의 작은 이미지 한 장만 불러옵니다. 전신·스페어·큰 보관본은 자동으로 읽지 않습니다. 그림은 장식 요소로 제공하며 버튼 클릭·키보드 이동을 막지 않고 인쇄 시 숨깁니다. 실제 박스 테두리에 맞춘 팔 접점과 머리카락의 겹침은 `public/menu-art.mjs`의 `overhang` 값으로 조정합니다.

## 폴더 정리

미사용 초기 UI 컴포넌트·훅·D1 예제 63개 파일을 정리했습니다. 연결 오류 UI에서 사용하는 `components/ui/button.tsx`는 유지했습니다. 삭제 목록은 [cleanup.json](./cleanup.json)에 있습니다.

초상화 라이브러리, 시트 원본 이미지, 월별 원본·아카이브, 보스 자동 매칭과 월말 갱신은 보존했습니다. `clan-battle/` 소스와 `docs/` 배포 미러는 서로 다른 용도여서 유지합니다.
