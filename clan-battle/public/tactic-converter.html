해외 택틱 자동 변환기

일본어 일반 택틱과 일본·중국식 당고(O/X, 〇/ー)를 한국어 ON/OFF 방식으로 변환합니다.

① 덱 순서와 이름 대응

덱 번호는 화면의 왼쪽이 1번, 오른쪽이 5번입니다. 동시 조작의 출력은 5→1 역순이며, 명시적으로 순서를 지정한 행동은 원문 순서를 유지합니다. 당고·번호형 택틱은 한국어 이름을 비워도 번호 순서대로 복사할 수 있습니다.

순서해외 원문 이름사이트 이름

일본어·중국어·한국어 별칭은 사이트 정식 이름으로 통일합니다. 직접 지정한 원문 이름과 한국어 이름의 대응도 이 브라우저에 기억합니다. 단, 당고의 1~5번 배치 순서는 반드시 확인해야 합니다.

본문 변환만 할 때는 이름 입력이 필요 없습니다. 번호로 복사하는 경우 붙여넣기 대상 택틱의 편성을 미리 지정해 주세요. 해외 원문 이름은 별칭까지 포함해 직접 수정할 수 있습니다.

② 해외 택틱 원문

시작 AUTO 설정이 없으면 AUTO 오프를 기본 적용합니다. 일반 명령과 당고가 중복 기재된 경우 일반 명령을 우선합니다. 결과는 ON → AUTO 온 → OFF → AUTO 오프를 우선하며, 초동 SET 및 명시적 조작 순서는 예외입니다. 화살표(➡)로 나뉜 서로 다른 시점의 ON은 '순으로 ON'으로 표시하고, 알려진 보스 이름은 사이트 보스 DB와 대조합니다.

③ 한국어 결과 미리보기

원문을 입력한 뒤 변환하기를 누르세요.

변환 결과가 나오면 본문만 복사할 수 있습니다.

자동 복사가 제한된 브라우저입니다. 아래 내용 전체를 선택한 뒤 PC는 Ctrl+C, 모바일은 복사를 눌러 주세요.

편성·SET 포함 복사는 각 행의 6개 체크 상태를 유지합니다. 실제 이름을 지정했다면 초상화도 자동 설정하며, 이름을 생략했다면 택틱 작업실의 기존 편성·초상화를 유지합니다.

④ 클전 사이트에 넣는 방법

  1. 본문만 복사 또는 편성을 지정한 경우 SET 포함 복사 버튼을 누릅니다.
  2. 기존 클전 사이트 → 택틱 작업실에서 작성 잠금을 해제하고 새 택틱의 첫 번째 빈 행으로 이동합니다. 실제 이름을 함께 복사했다면 5명 편성을 가져오며, 번호 모드라면 기존 편성 1~5번 이름으로 변환됩니다.
  3. 첫 번째 빈 택틱 행을 클릭하고 Ctrl+V (모바일: 붙여넣기) 합니다.
  4. 명령어의 빨강/파랑 표시와 캐릭터·AUTO 체크박스를 확인한 뒤 저장 상태를 확인합니다.

변환기는 데이터베이스를 직접 수정하지 않습니다. 원문이 모호한 경우 확인 경고가 나오며, 최종 적용 전에는 원본 영상과 대조해 주세요.
