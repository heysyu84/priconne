해외 택틱 자동 변환기

일본어 일반 택틱과 일본·중국식 당고(O/X, 〇/ー)를 한국어 ON/OFF 방식으로 변환합니다.

① 덱 순서와 이름 대응

왼쪽부터 실제 택틱의 1~5번 자리입니다. 원문 이름과 사이트에서 사용할 한국어 이름을 정확히 연결하세요.

순서해외 원문 이름사이트 이름

이름 순서가 틀리면 당고 체크 상태도 잘못 계산됩니다. 원문 이름은 별칭까지 포함해 직접 수정할 수 있습니다.

② 해외 택틱 원문

일반 명령과 당고가 한 게시물에 중복 기재된 경우 일반 명령을 우선합니다.

③ 한국어 결과 미리보기

덱 이름과 원문을 입력한 뒤 변환하기를 누르세요.

SET 포함 복사는 화면에 보이지 않는 6개 체크 상태를 각 행에 포함합니다. 클전 사이트에 붙여넣으면 기존 택틱 작업실이 이를 자동 인식합니다.

④ 클전 사이트에 넣는 방법

  1. SET 포함 복사 버튼을 누릅니다.
  2. 기존 클전 사이트 → 택틱 작업실에서 작성 잠금을 해제하고, 대상 택틱의 캐릭터 5명과 순서를 확인합니다.
  3. 첫 번째 빈 택틱 행을 클릭하고 Ctrl+V (모바일: 붙여넣기) 합니다.
  4. 명령어의 빨강/파랑 표시와 캐릭터·AUTO 체크박스를 확인한 뒤 저장 상태를 확인합니다.

변환기는 데이터베이스를 직접 수정하지 않습니다. 원문이 모호한 경우 확인 경고가 나오며, 최종 적용 전에는 원본 영상과 대조해 주세요.
