프리코네 초상화 합성 도구 · 클랜전

성급(별), 속성, 역할(롤) 이미지를 하나의 캐릭터 초상화에 합성하는 도구입니다.
기존 버전보다 성급을 개별 선택할 수 있고, 기본 초상화와 6성 초상화를 분리해서 사용할 수 있으며, 배치 위치를 직접 조절할 수 있습니다.

완성 PNG는 파일로 다운로드됩니다. 택틱 DB 및 기존 기록은 자동으로 변경되지 않습니다. 실제 택틱에 적용하려면 이미지 등록과 캐릭터 DB 갱신이 추가로 필요합니다.

1. 캐릭터 / 재료 설정

테두리가 있는 기존 GitHub 초상화는 사용하지 않습니다. 테두리 없는 신형 초상화를 사용하세요.
구형 초상화는 불러오지 않습니다. 캐릭터명만 가져오고, 테두리 없는 신형 초상화는 별도로 선택합니다.

신형 초상화 원본
위 이미지 자료실에서 파일명으로 검색해 선택하거나, 별도 PNG·WebP 파일을 아래에서 직접 업로드할 수 있습니다. 기존 클랜전의 구형 이미지는 새 원본으로 사용하지 않습니다.

캐릭터뿐 아니라 보스·심연보스·원본·배경·기타 이미지 전체를 탐색합니다. 검색 결과를 누르면 바로 원본으로 불러옵니다.

이미지 선택 전
비워두면 6성 생성 시에도 기본 초상화를 사용합니다.
합성 아이콘 직접 등록 (자동 로딩 실패 시)
예: 07.png는 명속성·힐러, 3.png·4.png·5.png·6.png는 성급 표시입니다. 별과 속성·롤 이미지를 모두 선택할 수 있습니다. 파일을 등록하면 외부 주소보다 우선합니다.
등록된 로컬 합성 아이콘 없음 (온라인에서 자동 로드)
고급 설정 (오피셜 위치 미세 조정)
위치는 가장자리로부터 떨어진 거리이며 크기는 128px 초상화 기준입니다. 미리보기에서 즉시 반영됩니다.
